# מנסח הקונספט המוצרי

## אחריות יחידה

לנסח את הקונספט המוצרי מהקנבסים המעודכנים והחלטת הפתרון — כטיוטה שאדם מאמץ.

## טריגר

**ידני.** אחרי [`dv-canvas-update`](../dv-canvas-update/SKILL.md).

## קלט

### חובה — בלעדיו הסוכן אינו רץ

| הקלט | מי מספק |
|---|---|
| כרטיס המיזם — `solution_decision.adopted = true` | המערכת |
| הקנבסים המעודכנים | [`dv-canvas-update`](../dv-canvas-update/SKILL.md) |
| ה-ADR של בחירת הפתרון | [`dv-decision-drafting`](../dv-decision-drafting/SKILL.md) |

### רשות — מעשיר, והיעדרו מדווח

**ערכי המיזם** (⬜ אנושי) · שאלת ה-MVP אם כבר נוסחה · תיעוד רעיונאות של הצוות · מסמך הגדרת הבעיה

### ידע — נקרא, לעולם לא משוכפל לתוך הסקיל

| מה | איפה |
|---|---|
| מבנה התוצר | [תבנית קונספט מוצרי](../../../06-כלים-ותבניות/קונספט-מוצרי-תבנית.md) |
| הנחות היסוד — ⭐ **הנחה 2: רשאי להציע שיטה** | [README שלב 3](../../../08-ארכיטקטורת-המימוש/03-mvp-poc/README.md) |

## תנאי כניסה

| התנאי | אם אינו מתקיים |
|---|---|
| קיים כרטיס מיזם עם `solution_decision.adopted = true` | **עצור.** החזר: "3.2 מתחיל אחרי שהחלטת הפתרון אומצה — Gate 3.1" |
| הקנבסים עודכנו | **עצור.** החזר: "קונספט על קנבסים של שלב 2 מתאר מוצר שלא נבחר" |
| ⚠️ ערכי המיזם מולאו | **המשך** — סעיף 2 נשאר **ריק ומסומן "ממתין לאדם"**. הסוכן לא ממציא ערכים |

> **אל תרוץ על קלט חלקי.**

## התהליך — 7 צעדים (ארכיטיפ הניסוח)

```
- [ ] 1. טען את התבנית — היא מגדירה את הסעיפים
- [ ] 2. סעיף 1 — מהקנבסים המעודכנים, עם "מה השתנה"
- [ ] 3. ⛔ סעיף 2 (ערכים) — אנושי · ריק ומסומן אם לא סופק
- [ ] 4. סעיף 3 — תכולה מהקנבסים + ADR · עמודת "ב-MVP?" נשארת ריקה עד שאלת ה-MVP
- [ ] 5. סעיף 4 (CX) — ⭐ רשאי להציע Journey Map / Persona כברירת מחדל · מסומן "הצעת שיטה"
- [ ] 6. העבר ל-md-output-review — עקביות מול הבריף, כרטיס הפתרון, ה-ADR
- [ ] 7. עצור בשער אימוץ אנושי
```

**5 · הצעת שיטה.** הצעה = *"כברירת מחדל מוצע Journey Map לבעל עניין X — הצוות רשאי לבחור שיטה אחרת."* לא = לבנות את ה-Journey Map כאילו הוסכם.

## פלט

מסמך לפי [התבנית](../../../06-כלים-ותבניות/קונספט-מוצרי-תבנית.md) — 5 סעיפים קבועים. מסומן טיוטה.

**בקרת מסירה:**

```
- [ ] כל שדה נושא מקור, או מסומן ריק
- [ ] הערכים לא מולאו ע"י הסוכן
- [ ] כל הצעת שיטה מסומנת כהצעה
- [ ] תכולה — כל רכיב משויך לבעל עניין
- [ ] אומץ ע"י אדם לפני Gate
```
