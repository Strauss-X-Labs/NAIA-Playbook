# Playbook — כור ההאצה

מפת הדרכים המלאה של כור ההאצה: מזיהוי בעיה לאומית ועד למיזם AI בשל, מאומת בשוק, ובסקייל. זהו הענף המתודולוגי — ניטרלי לתחום, חל על כל בעיה וכל כור.

**התחילו מ-[00-חזון-ועקרונות](00-חזון-ועקרונות/README.md)** — שם מוסבר גם קונספט ה-Wiki שעליו בנוי כל הריפו, לפני הכניסה לשלבים עצמם.

## זרימת השלבים (מבט-על)

```
1. מפעל הבעיות (מתמשך, ~80 בעיות/שנה)
        │  ~10 בעיות עוברות סינון
        ▼
2. הגדרת המיזם (חקר → רעיונאות → Lean Canvas → Roadshow)
        │  שותף מוביל חתום
        ▼
3. פיתוח (עיצוב המוצר וארכיטקטורה → מפת דרכים → הוכחת ערך/POV)
        │  "WoW, אני צריך את זה" — אצל משתמש בודד
        ▼
4. Production, PMF ו-Scale for Impact (מעבר לייצור → PMF: המוצר מתאים בול לשוק → הפצה רחבה + מדידת אימפקט לאומי)
```

שלבים 3–4 עשויים להשתמש בנספח [שיטת פיתוח אג'נטי ו-ADR](05-שיטת-פיתוח-אגנטי-וadr/README.md) כשמדובר בטרנספורמציה טכנולוגית של מערכות ליבה.

ראו יישום קונקרטי של השלבים בענף [`כורי-בינה/`](../כורי-בינה/README.md).
