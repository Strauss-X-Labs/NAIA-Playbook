# תת-שלב 3 · אסטרטגיה מוצרית — Lean Canvas

## מטרה

בניית המצפן העסקי של המיזם: הגדרת סגמנטים, הצעת ערך, ערוצים, שותפים, מדדי הצלחה ומודל עסקי — בתבנית Lean Canvas מותאמת למטה.

## עיקרון מרכזי: שני לקוחות תמיד — אזרח ושותף מיישם (שני פנים לקנבס)

הקנבס חייב לשקף שתי זוויות בו-זמנית:

1. **אימפקט לאומי** — איך תיראה הצלחה במונחי מציאות חדשה לאזרח
2. **מודל עסקי לשותף** — מה התמורה לשותף המיישם (חיסכון למשרד / רווח לחברה פרטית) — תמריץ לקחת בעלות

## מבנה ה-Lean Canvas המותאם

נבנה על-ידי ליבת ה-Mission Squad על-סמך כל המידע מ[חקר הבעיה](01-חקר-הבעיה.md) ו[הרעיונאות](02-רעיונאות-AI.md).

**עקרונות הבנייה:** נבנה LC אחד לכל פרסונה מרכזית שהוגדרה · על-פי כלל ה-LC שנערכו, מגדירים את מרכיבי ה-AI המאוחדים של המוצר.

**סעיפי חובה בקנבס:**

| סעיף | תוכן |
|---|---|
| בעיה | בעיות השורש שזוהו + חלופות קיימות |
| פתרון | מרכיבי הפתרון + תפקיד ה-AI |
| הצעת ערך ייחודית | מה מייחד את הפתרון שלנו |
| AI Components | היכולות הספציפיות של ה-AI במוצר |
| מדדי הצלחה | KPIs ומדדי אימפקט לאומי |
| קהל יעד | סגמנטים ופרסונות מרכזיות |
| ערוצים | כיצד מגיעים למשתמשי הקצה |
| מבנה עלויות | עלויות הקמה, תפעול, דאטה |
| מודל עסקי/תמורה | מה "מקבל" השותף המיישם |
| שותפים מרכזיים | גופים ממשלתיים, תעשייה, אקדמיה |

תבנית ריקה למילוי: [06-כלים-ותבניות/lean-canvas-תבנית.md](../06-כלים-ותבניות/lean-canvas-תבנית.md).

## מיפוי סיכונים וכשלונות מוקדמים

| סוג סיכון | דוגמאות |
|---|---|
| טכנולוגי | אין דאטה, AI לא מספיק בשל, אין Proof of Concept |
| רגולטורי | נדרש שינוי חוק, בעיות פרטיות, חסמי אבטחה |
| ארגוני | אין Product Owner, חוסר מחויבות ניהולית |
| פוליטי | שינוי ממשלה, התנגדות בעלי עניין |

> **עיקרון מרכזי: סיכון רגולטורי = ניהול סיכונים, לא פסילה.** שינוי רגולטורי לא פוסל מיזם — הוא מנוהל כסיכון ב"מפתחות להצלחה". מסלולי ההתקשרות והרכש (G2G, ספק יחיד, מכרז) מתוכננים מוקדם.

**מי מאשר:** ועדת ההיגוי של הנהלת המטה.

**תנאי סף:**
- [ ] כל סעיפי ה-Canvas מלאים

- [ ] מועמדים ל-Owner מזוהים

**תוצר:** בריף מיזם מסכם — 1–2 עמודים, פורמט מכירתי, מותאם לגיוס שותף מוביל. ראה [RFI — סקירת פתרונות אפשריים](04-rfi-פתרונות-אפשריים.md), ולאחריו [Roadshow](05-roadshow-ובחירת-שותפים.md).
