# ארכיטקטורת המימוש — סוכני AI ו-Skills

> פרק 08 | עבודה משותפת של ליאור (הארכיטקט הראשי) ו-Claude (שותפה לתכנון) | גרסה חיה, נבנית פרק-פרק

## מה זה הפרק הזה

הפרקים 00-07 מגדירים **מה** קורה בכל שלב של כור ההאצה. הפרק הזה מגדיר **איך** — הארכיטקטורה הקונקרטית של סוכני ה-AI וה-Skills שמפעילים כל שלב בפועל: אילו סוכנים קיימים, מה האחריות היחידה של כל אחד, מתי הוא פועל, ומי מאשר את הפלט שלו.

**עיקרון יסוד:** הפרק הזה **לא ממציא תהליך חדש** — הוא מתרגם את מה שכבר מתועד בפרקים 00-07 (אלגוריתמים, RACI, בקרת עלות, עקרונות-על) לצנרת סוכנים מפורשת, ומוסיף רק את מה שבאמת חסר (בעיקר: שכבת הזנת מידע גולמי).

## מבנה העבודה

- עובדים **שלב-שלב**, לפי סדר שלבי כור ההאצה (00-חזון-ועקרונות → 01-מפעל-הבעיות → 02-הגדרת-המיזם → ...)
- לכל שלב: קודם עיצוב משותף בשיחה, ורק אחרי הבנה מלאה — כתיבה בפועל לקובץ
- שלב נחשב "סגור" רק כשהוסכם במפורש; רק אז עוברים לשלב הבא

## סטנדרטים למסמך ארכיטקטורה (מבוסס Design Session, "הארכיטקט הפשוט")

כל מסמך עיצוב בפרק הזה עוקב אחרי אותו שלד קבוע:

| סעיף | מה נכנס בו |
|---|---|
| תרגום אנושי | 3 משפטים: מה בונים, למה דווקא כך, מה במפורש לא עכשיו |
| הבעיה והאנשים | הערך, מי מעורב (RACI קיים), האילוץ הדומיננטי |
| המבנה | תרשים הצינור/הזרימה + מבנה ספריות/קבצים |
| החלטות מפתח | כל החלטה מהותית: מה, למה, נתיב יציאה אם טעינו |
| מה במפורש לא עכשיו | הגנה מודעת על הפשטות |
| צעדים ראשונים | 3-5 צעדים קונקרטיים |

**עקרונות-על שחלים על כל סוכן/Skill שמתוכנן כאן** (הוסכמו 29-30.08.2026):

1. **SOLID** — ובראש ובראשונה Single Responsibility: כל סוכן עושה דבר אחד מוגדר היטב
2. **ברור ופשוט** — תמיד עדיפות לפתרון הפשוט ביותר שעובד
3. **3 אופני פעולה**: **לפני** (הכנת מידע/חומר) · **במהלך** (סיוע אינטראקטיבי לבן אדם בזמן אמת) · **אחרי** (תיעוד/המשך לאחר שאדם סיים)
4. **Human in the Loop תמיד** — סוכן מציע (Responsible), אדם מחליט (Accountable). זהו עיקרון-העל הכללי של הריפו ([00-חזון-ועקרונות](../00-חזון-ועקרונות/README.md#עיקרון-העל-human-in-the-loop-תמיד)) וחל כאן ללא יוצא מן הכלל

**פרוטוקול עבודה:** בכל נקודת החלטה/אי-בהירות, מוצגות **4 אפשרויות** לבחירה/שילוב/הצעה חלופית — לא ממשיכים על בסיס הנחה חד-צדדית.
