## מפת-העל — 7 תתי-תהליכים

```
                    ┌─────────────────────────────────────┐
                    │   בקרת עלות והרצות (חוצה-הכל)        │
                    │   Schedule / On-Demand / Trigger      │
                    └─────────────────────────────────────┘
                    ┌─────────────────────────────────────┐
                    │   תיעוד + Human-in-the-Loop (חוצה-הכל)│
                    └─────────────────────────────────────┘
                    ┌─────────────────────────────────────┐
                    │   סוכן-ליווי — "במהלך" (חוצה-הכל)     │
                    │   On-Demand בזמן אמת: SME / הכרעה     │
                    └─────────────────────────────────────┘

A. הזנה וסיווג  ──►  B. תיעדוף/ניקוד  ──►  C. תיעדוף דינמי  ──►  I. מי הבאה?  ──►  G. שער יציאה
   גולמי→ניתוח→          אלגוריתם 0-5,       עדכון ציון שוטף,      רשימה מדורגת       Domain Lead+COO
   טיוטה/עדכון            ועדת תיעדוף,        חזרה למאגר,           עם נימוק בעד/נגד   מציגים ציון+
                          3 טריגרי הסלמה      Management Layer      ▲                  הנמקה+סיכונים
                                                    ▲               │
E. סריקת קו-אופק ──────────────────────────────────┘               │
   (מזין טריגר חזרה לבעיות מושהות)                                  │
                                                    ┌───────────────┘
D. Funnel Review רבעוני (חוצה A-C, תמהיל 70/30) ────┘  טריגר: התפנה משאב Mission Lead

F. הרכבת צוות אד-הוק לחקר בעיה פעילה (Domain Lead + Domain Experts)

⛔ אילוץ: שיתוף משרדי ממשלה — לא בשלב הזה (רק ב-הגדרת-המיזם)
```

**שכבות חוצות-הכל:** בקרת עלות (Schedule/On-Demand/Trigger) · תיעוד + Human-in-the-Loop · סוכן-ליווי ("במהלך") · **H — ניהול פרמטרים** (חוצה גם שלבים, לא רק תתי-תהליכים)
