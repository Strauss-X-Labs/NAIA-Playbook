# הגדרת המיזם

> שלב ב׳ של כור ההאצה

## סקירת השלב

שלב הגדרת המיזם הוא הגשר בין בעיה נבחרת מ[מפעל הבעיות](../01-מפעל-הבעיות/README.md) לבין מיזם בשל לביצוע. המטרה: לצלול לעומק הבעיה, לגבש כיוון פתרון מבוסס AI, לבנות מצפן עסקי ולגייס שותף מוביל שיקח בעלות.

**עיקרון מרכזי: אחריות משתנה לאורך השלבים, מעורבות תמידית.** בשלב הזה המטה הוא גם ה-Responsible וגם ה-Accountable — מזהה, חוקר, בוחר ומגבש את המיזם בעצמו, שכן טרם נכנס שותף מוביל. המטה **אינו מפתח את הפתרון המלא**: הוא יוצר "בריף" המגדיר את מצפן המיזם ואת הקריטיות של AI, ומאפשר לשותף חיצוני לקחת בעלות על הביצוע בשלב הבא (פיתוח) — שם האחריות התפעולית עוברת לשותף המוביל, והמטה נשאר Accountable על התהליך עצמו. טבלת ה-RACI המלאה לכל השלבים: [עיקרון העל: אחריות משתנה לאורך השלבים, מעורבות תמידית](../00-חזון-ועקרונות/README.md#עיקרון-העל-אחריות-משתנה-לאורך-השלבים-מעורבות-תמידית).

**תפוקת השלב:** מסמך הגדרה מפורט + בריף מיזם שיסייע בבחירה וברתימה של השותף המתאים, המוכן ל-Roadshow.
