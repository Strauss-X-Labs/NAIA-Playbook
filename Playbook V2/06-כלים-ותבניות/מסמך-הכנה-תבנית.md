## 0 · מקורות שנסרקו

| מקור | סוג | תאריך סריקה | מצב | הערה / סיבה |
|---|---|---|---|---|
| | | | נסרק-והניב · נסרק-ולא-הניב · **לא-נסרק** | |

> ⛔ **כל מקור במרשם מופיע כאן — גם מי שלא נסרק.** מקור שאינו מופיע נחשב **כשל בסריקה**.
> **ההבחנה הקריטית:** "נסרק-ולא-הניב" = בדקנו, אין שם כלום. "לא-נסרק" = לא בדקנו.
> **מסמך שמכיל רק את הראשון נראה מקיף גם כשסרק שליש מהמרשם.**

**פריטים ממקבץ הבקרה המוגברת** — **עוגן חובה לכל פריט**:

| הפריט | הקישור הישיר | תאריך תפיסה | ⭐ מי הדובר ומה שיוכו |
|---|---|---|---|
| | | | |

> התוכן שם **נמחק ונערך**. פריט בלי עוגן אינו ניתן לאימות בדיעבד ולכן אינו קביל. **הייחוס הוא לדובר, לא לפלטפורמה** — "נאמר ביוטיוב" אינו ייחוס.

> המרשם: [מקורות מידע](../01-מפעל-הבעיות/מקורות-מידע.md) · [הרשימה המורחבת](../07-נספחים/רשימת-מקורות-מורחבת.md). פותחים מכל מקור שמהימנותו **"מהימן"**, ומרחיבים משם.
