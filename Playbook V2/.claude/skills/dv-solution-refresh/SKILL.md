> **אל תרוץ על קלט חלקי.** תוצר שנבנה על חוסר **נראה שלם**.

## התהליך — 5 צעדים (ארכיטיפ הריכוז)

```
- [ ] 1. קלוט את הטבלה כפי שהיא — שורה-שורה
- [ ] 2. לכל שורה: בדוק מול המקור הנוכחי · סווג: תקף / השתנה / נעלם
- [ ] 3. חפש כניסות חדשות מאז ה-RFI · סווג: חדש
- [ ] 4. ⛔ אל תדרג · אל תמליץ · אל תסנן "לא רלוונטי"
- [ ] 5. סמן מה לא הצלחת לתקף — במקום להשמיט
```

**2 · תיקוף.** "השתנה" חייב לומר **מה** השתנה — מחיר · יכולת · זמינות · בעלות. "נעלם" חייב מקור.
**3 · חדש.** ספק שלא ענה ל-RFI ומופיע עכשיו — נכנס כ**"חדש · דורש סימוכין"**. לעולם לא כ"תקף".

## פלט

הטבלה המקורית + **עמודת מצב** + סעיף "מה השתנה מאז ה-RFI":

| הפתרון | … (עמודות ה-RFI) … | **מצב** | **מה השתנה** | **מקור התיקוף** | **מהימנות** |
|---|---|---|---|---|---|
| | | תקף · השתנה · נעלם · חדש | | | |

**בקרת מסירה:**

```
- [ ] כל שורה מהטבלה המקורית מופיעה — גם "נעלם"
- [ ] כל "השתנה" אומר מה השתנה, עם מקור
- [ ] כל "חדש" מסומן דורש סימוכין
- [ ] לא בוצע דירוג או המלצה
- [ ] מה שלא תוקף — סומן, לא הושמט
```
